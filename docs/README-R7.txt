QLBox R7: runtime CPU speed controls

Ctrl+F12: increase CPU speed by 1x, up to 64x.
Ctrl+F11: decrease CPU speed by 1x, down to 1x.
Ctrl+F10: return to 1x.
The window title shows the selected CPU multiplier.
Boot defaults to 1x; --speed N still selects the initial speed.
Timers and audio retain their real-time rate. Higher settings request more
CPU work per frame; actual speed depends on the host keeping up.
Plain F12 still exits. Speed hotkeys are consumed by the host.

R6 ROM, storage and beeper are unchanged. Windows 32/64 binaries included.
Sarien beeper R4 remains the separate working application sound baseline.
