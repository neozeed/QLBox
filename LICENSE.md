# Component provenance

Musashi's existing permissive license is retained in its source headers and
vendor/musashi/readme.txt. QLAY informed IPC, keyboard and video implementation;
its notice is retained in docs/QLAY-LICENSE.txt. Bundled SDL2 DLLs are from the
2.30.0 MinGW package; see docs/SDL2-LICENSE.txt.

The supplied Sinclair ROM/disassembly retains its existing provenance; this
project does not assert a new license to it.

The UNZIP532 and UNZIP541 samples are unchanged Info-ZIP QDOS executables
recovered from user-provided BASIC wrappers. Their original embedded credits
and provenance remain; see docs/UNZIP.md and samples/unzip.

R5 includes corrected user-supplied Sarien QL source under samples/sarienQL-fixed.
Its original copyright and GNU GPL notices are retained. No Sierra game data is included.

R20 embeds the unchanged user-supplied QDOS Info-ZIP 2.3 binary as ROM1_ZIP.
Its embedded license is reproduced in docs/ZIP-LICENSE.txt. This package does
not claim to include the original ZIP utility source. Toolkit II and QSound
firmware retain their original embedded notices and provenance.

For the component-by-component source map and acknowledgements, see
[docs/PROVENANCE.md](docs/PROVENANCE.md). This documentation edition does not
change any component license.
